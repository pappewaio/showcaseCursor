# Cursor AI Showcase

## What is Cursor?

Cursor is an AI-first code editor built for pair programming with AI. It enhances your coding workflow with intelligent features like:

- **AI-assisted coding** - Get real-time code completions and suggestions
- **Natural language commands** - Explain what you want to do in plain English
- **Code understanding** - Ask questions about code and get meaningful answers
- **Automated refactoring** - Transform code with simple instructions
- **Bug fixing** - Identify and fix issues with AI assistance

## 🚀 Quick Demo (20 Minutes)

### 1. Basic Coding with AI (5 minutes)

1. **New File Creation**: Create a new file with `/new` command
   ```
   /new React component that shows a todo list with completion status
   ```

2. **Code Explanation**: Ask the AI about code you don't understand
   ```
   /ask What does this component do? How does it manage state?
   ```

3. **Real-time Suggestions**: Start typing and see AI autocomplete suggestions

### 2. Refactoring & Improvement (5 minutes)

1. **Code Transformation**: Convert code to use modern patterns
   ```
   /edit Convert this to use React hooks instead of class components
   ```

2. **Performance Optimization**: Ask for performance improvements
   ```
   /edit Optimize this component for better performance
   ```

3. **Adding Features**: Extend functionality with simple instructions
   ```
   /edit Add filtering capability to this todo list by status
   ```

### 3. Problem Solving & Debugging (5 minutes)

1. **Bug Fixing**: Identify and fix issues
   ```
   /fix There's a bug when I add a new todo item, it's not showing up
   ```

2. **Testing**: Generate tests
   ```
   /new Create test cases for this todo component
   ```

### 4. Advanced Capabilities (5 minutes)

1. **Multi-file Understanding**: Ask about project architecture
   ```
   /ask How do these components interact with each other?
   ```

2. **Documentation**: Generate documentation
   ```
   /edit Add detailed JSDoc comments to this file
   ```

3. **API Integration**: Add external service connections
   ```
   /edit Add functionality to save todos to localStorage
   ```

## 💡 Tips for Effective AI Pairing

- Be specific in your requests
- Iterate on AI suggestions
- Combine commands for complex tasks
- Ask follow-up questions if the AI's response isn't quite right
